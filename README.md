# سامانه هوشمند برنامه‌ریزی تحصیلی آکادمی دکتر فروتن کیا
### نسخه 1.0.0

سامانه‌ای مدرن، کاربردی و منطبق با هویت بصری رسمی **آکادمی مشاوره دکتر فروتن کیا** برای مشاوران تحصیلی جهت طراحی و صدور دفترچه‌های اختصاصی برنامه‌ریزی هفتگی کنکور در قالب فایل استاندارد A4 با زبان فارسی و چینش کامل راست‌به‌چپ (RTL).

---

## ساختار ۴ صفحه دفترچه برنامه

* **صفحه ۱ (طرح جلد لوکس)**:
  - آرم رسمی آکادمی دکتر فروتن کیا در کادر مخصوص + عنوان بزرگ «برنامه مطالعاتی» + کادر سال تحصیلی و هفته.
  - کارت مشخصات شناسنامه‌ای دانش‌آموز، نام مشاور، رشته تحصیلی، نام مدرسه و بازه زمانی.
* **صفحه ۲ (جدول هفتگی مطالعه در عرض کامل ۲۹۷mm - چیدمان ترنسپوز)**:
  - **ساختار ابعادی کاملاً ثابت (`table-layout: fixed`)**: پارت‌ها در ستون‌ها و روزهای هفته در سطرها با تفکیک دقیق سطر مبحث و سطر تست.
  - پشتیبانی از ۲ تا ۱۴ روز مطالعه، پارت روتین شبانه، کپی و جای‌گذاری هوشمند سلول‌ها، روزها و ستون‌ها، و توزیع خودکار چندصفحه‌ای بدون تداخل.
* **صفحه ۳ (شناسنامه و مشخصات دانش‌آموز)**:
  - شبکه استاندارد برای مشخصات اصلی (نام و نام خانوادگی، رشته تحصیلی، مدرسه، مشاور ناظر، مشاور، شماره تماس، آزمون‌ها، هفته، بازه زمانی).
  - کادر عریض و خوانا برای توضیحات تکمیلی و توصیه‌های استراتژیک مشاور.
* **صفحه ۴ (گزارش وضعیت مطالعه)**:
  - سربرگ رسمی با نشان صفحه، نام دانش‌آموز و هفته.
  - جدول منابع و سرفصل‌های مطالعاتی (شامل ردیف، نام کتاب و منبع مطالعاتی، مباحث و فصول خوانده‌شده، و یادداشت).
  - جدول اختصاصی رشته علوم انسانی و پذیرش فرهنگیان با تفکیک دقیق پایه‌های دهم، یازدهم و دوازدهم.
  - صفحه‌بندی هوشمند خودکار (Multi-page Pagination) در صورت افزایش تعداد منابع.

## نحوه استفاده

1. فایل **index.html** را در هر مرورگر مدرنی (مانند Google Chrome یا Microsoft Edge) باز کنید.
2. همچنین می‌توانید در صورت تمایل با اجرای دستورات زیر سرور محلی را اجرا کنید:
   ```bash
   npm install
   npm start
   ```
3. تغییرات فرم را اعمال نمایید و با زدن دکمه **«چاپ / ذخیره PDF»** خروجی استاندارد خود را چاپ یا به عنوان فایل PDF ذخیره کنید.
