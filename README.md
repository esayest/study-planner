سامانه‌ای مدرن، کاربردی و منطبق با هویت بصری رسمی **آکادمی مشاوره دکتر فروتن کیا** برای مشاوران تحصیلی جهت طراحی، مدیریت و صدور دفترچه‌های اختصاصی برنامه‌ریزی هفتگی کنکور در قالب فایل استاندارد A4 با زبان فارسی و چینش کامل راست‌به‌چپ (RTL). این برنامه به صورت نرم‌افزار نیتیو دسکتاپ (ویندوز)، اپلیکیشن موبایل (اندروید) و نسخه تحت وب قابل استفاده است.

## ✨ قابلیت‌های کلیدی سامانه

- **دفترچه ۴ صفحه‌ای اختصاصی کنکور**: طراحی دقیق صفحات با نسبت ابعادی دقیق و چیدمان لوکس سازمانی.
- **موتور صدور PDF با دقت چاپی بالا**: خروجی استاندارد ابعاد A4 با تفکیک دقیق صفحات چاپی (`@media print`) بدون به‌هم‌ریختگی یا افت کیفیت فونت‌ها.
- **جدول هفتگی ترنسپوز (Transposed Schedule)**: نمایش افقی و خوانا با تفکیک سطرهای «مبحث» و «تست» برای هر پارت مطالعاتی.
- **روتین شبانه و پارت‌های منعطف**: پشتیبانی از ۲ الی ۱۴ روز برنامه‌ریزی به همراه بخش ویژه روتین شبانه.
- **ابزارهای هوشمند جدول**: کپی و پیست سریع سلول‌ها، جابه‌جایی روزها، توزیع خودکار دروس و پاک‌سازی سریع.
- **تفکیک رشته انسانی و فرهنگیان**: جداول اختصاصی منابع با دسته‌بندی پایه‌های دهم، یازدهم و دوازدهم.
- **کاملاً آفلاین (Offline-First)**: عملکرد مستقل بدون نیاز به اتصال اینترنت با ذخیره‌سازی خودکار اطلاعات در مرورگر و برنامه.
- **پشتیبانی از حالت تیره و روشن (Dark / Light Mode)**: رابط کاربری مدرن منطبق با استانداردهای ارگونومی چشم.
- **تک‌نمونه‌ای بودن در ویندوز (Single Instance)**: ممانعت از باز شدن چندباره برنامه و هدایت کاربر به پنجره فعال فعلی.

## 📑 ساختار صفحات دفترچه برنامه

1. **صفحه ۱ (طرح جلد لوکس)**:
   - نشان رسمی آکادمی دکتر فروتن کیا در کادر اختصاصی.
   - کارت مشخصات دانش‌آموز، نام مشاور، رشته، مدرسه و بازه زمانی برنامه.
2. **صفحه ۲ (جدول هفتگی مطالعه در عرض کامل ۲۹۷mm)**:
   - ساختار ابعادی کاملاً ثابت (`table-layout: fixed`) جهت جلوگیری از جابه‌جایی ابعاد.
   - پارت‌های مطالعاتی در ستون‌ها و روزهای هفته در سطرها به همراه بخش مرور و روتین شبانه.
3. **صفحه ۳ (شناسنامه و مشخصات دانش‌آموز)**:
   - جدول جامع اطلاعات تحصیلی، شماره تماس، سوابق آزمون و بازه برنامه‌ریزی.
   - کادر عریض برای توصیه‌های کلیدی، استراتژی مشاور و نکات طلایی مطالعه.
4. **صفحه ۴ (گزارش وضعیت مطالعه و منابع)**:
   - سربرگ رسمی با نام دانش‌آموز و هفته مطالعاتی.
   - جدول منابع و مباحث خوانده‌شده با صفحه‌بندی هوشمند خودکار (Multi-page Pagination).
   - جدول اختصاصی داوطلبان رشته علوم انسانی و پذیرش دانشگاه فرهنگیان.

## 🛠️ معماری فنی و فناوری‌ها

- **هسته دسکتاپ و موبایل**: [Tauri v2](https://tauri.app/) مبتنی بر زبان Rust (امن، سبک و با کمترین مصرف منابع حافظه).
- **رابط کاربری (Frontend)**: جاوااسکریپت خالص (Vanilla ES6+)، CSS3 مدرن، HTML5 استاندارد.
- **تایپوگرافی فارسی**: خانواده قلم‌های رسمی **دانا (Dana)**، **پیدا (Peyda)** و **استعداد (Estedad)**.
- **یکپارچه‌سازی مداوم (CI/CD)**: پایپ‌لاین‌های خودکار [GitHub Actions](https://github.com/esayest/study-planner/actions) برای کامپایل و انتشار همزمان نسخه‌های ویندوز و اندروید در فضای ابری.

## 💻 راهنمای اجرا و توسعه محلی

### پیش‌نیازها
- **Node.js** (نسخه 18 یا بالاتر)
- **Rust** (در صورت کامپایل محلی کلاینت نیتیو)

### اجرای وب‌سایت و پرتال معرفی:
```bash
# اجرای وب‌سایت معرفی نرم‌افزار روی پورت ۴۰۰۰
npm run website
```

### اجرای نسخه تحت وب سامانه:
```bash
# اجرای سرور محلی نرم‌افزار روی پورت ۳۰۰۰
npm start
```

### ساخت بسته‌های نرم‌افزاری محلی:
```bash
# بیلد کلاینت ویندوز (تولید فایلهای exe و msi)
npm run tauri build

# بیلد کلاینت اندروید (تولید فایل apk)
npm run tauri android build
```

*(نکته: با توجه به فعال بودن پایپ‌لاین ابری GitHub Actions، تمامی بیلدها با پوشیدن بر روی برنچ اصلی یا انتشار تگ نسخه به صورت خودکار کامپایل و آماده دریافت می‌شوند).*
